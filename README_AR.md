# مشوار — بناء APK عبر GitHub Actions

## رفع المشروع من الهاتف
1. فك ضغط الملف على هاتفك.
2. أنشئ مستودع GitHub جديدًا باسم Mishwar، ويفضل أن يكون Private.
3. داخل المستودع اختر Add file ثم Upload files.
4. ارفع محتويات هذا المجلد (ملفات `build.gradle` و`settings.gradle` ومجلد `app` ومجلد `.github`) إلى جذر المستودع. لا ترفع مجلدًا خارجيًا يضمها جميعًا.
5. اضغط Commit changes.

## بناء APK
1. افتح تبويب Actions في المستودع.
2. اختر Build Mishwar APK.
3. اضغط Run workflow ثم Run workflow.
4. انتظر حتى ينتهي التشغيل. إذا كانت العلامة خضراء، افتح التشغيل وانزل إلى Artifacts.
5. نزّل `mishwar-debug-apk` وفك ضغطه لتحصل على `app-debug.apk`.

هذا APK تجريبي للتثبيت والاختبار وليس إصدارًا موقّعًا للنشر على المتجر. إذا فشل البناء، افتح التشغيل الأحمر وانسخ رسالة الخطأ الأخيرة.
